QUESTION:
Write a Java program to count the number of digits in a given number.

EXPLANATION:
The number of digits represents the total count of individual digits present in a given number.

We can count the digits using the division (/) operator.

Steps:
1. Read a number from the user.
2. Initialize a counter variable to zero.
3. Divide the number by 10 to remove its last digit.
4. Increment the counter by one for each digit removed.
5. Repeat the process until the number becomes zero.
6. Display the total count of digits.

TEST CASES:

Test Case 1:
Input: 12345
Expected Output: 5

Test Case 2:
Input: 987
Expected Output: 3

Test Case 3:
Input: 456789
Expected Output: 6

Test Case 4:
Input: 1002
Expected Output: 4

Test Case 5:
Input: 7
Expected Output: 1
