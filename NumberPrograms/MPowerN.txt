Question: Find the Value of M Raised to the Power N

Explanation:

M Power N means calculating the value of a number M raised to the power N.

It is represented as Mⁿ.

It means multiplying M by itself N times.

Logic:

1. Read two numbers M and N.
2. Initialize the result as 1.
3. Multiply the result by M repeatedly, N times.
4. After completing the multiplication, display the result.

Example:

Input: M = 2, N = 3

Calculation:

2³ = 2 × 2 × 2

= 8

Output: 8

Test Cases:

1. Input: M = 2, N = 3
   Output: 8

2. Input: M = 3, N = 2
   Output: 9

3. Input: M = 5, N = 3
   Output: 125

4. Input: M = 10, N = 2
   Output: 100

5. Input: M = 7, N = 0
   Output: 1
