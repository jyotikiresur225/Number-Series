XYLEM AND PHLOEM NUMBER

Question

Write a program to check whether a given number is a Xylem Number or a Phloem Number.

Explanation

A Xylem Number is a number in which the sum of the extreme digits is equal to the sum of the middle digits.

A Phloem Number is a number in which the sum of the extreme digits is not equal to the sum of the middle digits.

The extreme digits are the first and last digits of the number. The middle digits are all the digits between them.

Logic

1. Take the given number as input.
2. Initialize two variables named extremeSum and meanSum to 0.
3. Extract the last digit and add it to extremeSum.
4. Remove the last digit from the number.
5. Extract the first digit of the remaining number and add it to extremeSum.
6. Add all the remaining middle digits to meanSum.
7. Compare extremeSum and meanSum.
8. If both are equal, the number is a Xylem Number.
9. Otherwise, the number is a Phloem Number.

Example

Number: 1234

Extreme digits are 1 and 4.

Extreme sum = 1 + 4 = 5

Middle digits are 2 and 3.

Middle sum = 2 + 3 = 5

Since both sums are equal, 1234 is a Xylem Number.

Test Cases

1. Input: 1234
   Output: Xylem Number

2. Input: 12345
   Output: Phloem Number

3. Input: 121
   Output: Xylem Number

4. Input: 1254
   Output: Phloem Number

5. Input: 123456
   Output: Xylem Number
