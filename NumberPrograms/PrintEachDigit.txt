QUESTION:
Write a Java program to print each digit in a given number.

EXPLANATION:
A digit is an individual number present in a given number. We can extract each digit using the modulus (%) and division (/) operators.

1. Read a number from the user.
2. Use the modulus (%) operator to extract the last digit.
3. Print the extracted digit.
4. Use the division (/) operator to remove the last digit.
5. Repeat the process until the number becomes zero.
