Smallest Digit:

 Question:
Write a program to find the smallest digit in a given number.

 Explanation:
The smallest digit of a number is the digit with the lowest numerical value among all the digits present in that number.

For example, in the number 5824, the smallest digit is 2.

Logic:
1. Take the given number as input.
2. Initialize a variable named smallest with 9.
3. Extract the last digit of the number.
4. Compare the extracted digit with the current smallest digit.
5. If the extracted digit is smaller, update the smallest digit.
6. Remove the last digit from the number.
7. Repeat the process until all digits are checked.
8. The final value of smallest is the smallest digit in the given number.

Example:

Number: 5824

The digits are 5, 8, 2 and 4.

The smallest digit among them is 2.

Therefore, the smallest digit of 5824 is 2.

Test Cases:

1. Input: 5824
   Output: 2

2. Input: 7391
   Output: 1

3. Input: 456
   Output: 4

4. Input: 888
   Output: 8

5. Input: 1025
   Output: 0
