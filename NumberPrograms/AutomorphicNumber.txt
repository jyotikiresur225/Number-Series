Question: Check Whether a Number is an Automorphic Number or Not

Explanation:

An Automorphic Number is a number whose square ends with the same digits as the original number.

To check whether a number is an Automorphic Number:

- Find the square of the given number.
- Compare the last digits of the square with the original number.
- If both match, it is an Automorphic Number. Otherwise, it is not an Automorphic Number.

Example:

Number = 25

Square = 25 × 25 = 625

The square 625 ends with 25.

Since the last digits of the square are equal to the original number, 25 is an Automorphic Number.

Test Cases:

1. Number = 5 → Output = Automorphic Number (5² = 25)
2. Number = 6 → Output = Automorphic Number (6² = 36)
3. Number = 25 → Output = Automorphic Number (25² = 625)
4. Number = 7 → Output = Not an Automorphic Number (7² = 49)
5. Number = 76 → Output = Automorphic Number (76² = 5776)
